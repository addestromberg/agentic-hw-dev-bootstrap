# RSIM

Racing simulator cockpit hardware project. The workspace is being prepared;
hardware requirements and designs have not yet been established.

- [Project rules and directory structure](user/docs/project-rules.md)
- [Hardware modules](user/modules/README.md)
- [Agent instructions](AGENTS.md)
- [Tool and MCP setup status](agent/docs/toolchain.md)

Create a module with `python3 agent/scripts/new_module.py <module-name>`.
FreeCAD, KiCad and Blender are managed with pacman; project automation and evidence
stay under `agent/`.
